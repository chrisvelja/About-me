# Chris Velja — personal website

Static personal website for GitHub Pages.

## Structure
- `index.html` — main page
- `styles.css` — visual design
- `script.js` — theme toggle
- `.nojekyll` — keeps GitHub Pages from applying Jekyll processing

The current design follows the supplied website concept: large editorial hero, project archive, technical interests, vinyl-style music section, books shelf and contact area.
